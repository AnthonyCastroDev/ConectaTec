# ConectaTec
O ConectaTec é uma plataforma web que conecta alunos da Fatec a empresas da região. A ideia é dar aos estudantes um espaço para mostrar seus perfis, habilidades e projetos, e às empresas uma forma simples de encontrar e conhecer esses talentos. Ele é pensado para a realidade da comunidade acadêmica da Fatec e das empresas ao seu redor.

## Objetivo do projeto

O objetivo do projeto é aplicar conceitos de desenvolvimento de software criando uma aplicação web que aproxime alunos da Fatec e empresas da região.

Conceitos e práticas (a confirmar conforme o desenvolvimento):

* Controle de versão com Git e GitHub
* Diagramas UML
* Prototipação da interface gráfica com Figma
* Sitema de Login/Cadastro
